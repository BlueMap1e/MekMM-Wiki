## 元数据

**注册名**：`mekmm:silver_ore`

**NeoForge标签**：`c:ores`, `c:ores/silver`

## 概述

**银矿石（Silver Ore）**是本模组添加的一种矿石，用于生产。

---

## 生成规则

银矿石生成于Y=-32到Y=88之间。最密集的区域在Y=16到Y=32之间。

### 生成规则详解

银矿石拥有两套生成规则，小型矿脉与大型矿脉。运作方式分别如下表所示：

|       参数       | 小型矿脉 | 大型矿脉 |
| :--------------: | :------: | :------: |
|  单区块尝试次数  |    16    |    10    |
|  单矿簇最大大小  |    4     |    8     |
|   高度分布形态   | 三角分布 | 三角分布 |
|   最低生成高度   |  Y=-24   |  Y=-32   |
|   最高生成高度   |   Y=88   |   Y=64   |
| 生成概率最大高度 |   Y=32   |   Y=16   |
|   暴露空气废弃   |   0.0%   |   0.0%   |
