# MekMM Wiki

「通用机械:更多机器(Mekanism: More Machine)」非官方中文社区维基。

- 在线站点:https://mekmm-wiki.pages.dev
- 源码仓库:https://github.com/BlueMap1e/MekMM-Wiki
- 模组仓库:[lostmyself8/Mekanism-MoreMachine](https://github.com/lostmyself8/Mekanism-MoreMachine)

基于 [Astro](https://astro.build) + [Starlight](https://starlight.astro.build) 构建,部署在 Cloudflare Pages。

## 快速开始

```bash
git clone https://github.com/BlueMap1e/MekMM-Wiki.git
cd MekMM-Wiki
npm install
npm run dev      # 开发服务器
npm run build    # 构建产物到 dist/
```
